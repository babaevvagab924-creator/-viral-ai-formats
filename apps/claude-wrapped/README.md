# Claude Wrapped

Итоги общения с Claude в стиле Spotify Wrapped: 10 сторис-карточек по твоему экспорту чатов из claude.ai.

## Что считает

- количество чатов, сообщений и активных дней;
- сколько слов написал Claude (в романах) и сколько написал ты (в страницах);
- пиковый час и «хронотип» (жаворонок, вечерний творец, ночная сова);
- любимый день недели и рекордную серию дней подряд;
- топ-5 тем по названиям чатов;
- самый длинный разговор и самый активный месяц;
- «тип пользователя»: Инженер, Креатор, Исследователь, Стратег, Собеседник;
- примерную экономию времени (слова Claude ÷ 20 слов в минуту).

## Как пользоваться

1. claude.ai → Настройки → Конфиденциальность → **Экспорт данных**.
2. Скачай ZIP из письма.
3. Открой `index.html` в браузере и загрузи ZIP (или `conversations.json` из него).

Всё считается локально в браузере, файл никуда не отправляется.
Без файла приложение показывает пример на выдуманных данных (помечен плашкой «Пример»).
