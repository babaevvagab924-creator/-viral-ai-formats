# Компромат

Итоги года с Claude в стиле Spotify Wrapped: 10 сторис-карточек по твоему экспорту чатов из claude.ai.

## Что считает

- количество чатов, сообщений и активных дней;
- сколько слов написал Claude (в романах) и сколько написал ты (в страницах);
- пиковый час и «хронотип» (жаворонок, вечерний творец, ночная сова);
- любимый день недели и рекордную серию дней подряд;
- топ-5 тем по названиям чатов;
- самый длинный разговор и самый активный месяц;
- «тип пользователя»: Инженер, Креатор, Исследователь, Стратег, Собеседник;
- примерную экономию времени (слова Claude ÷ 20 слов в минуту).

## Как пользоваться

1. claude.ai → Настройки → Конфиденциальность → **Экспорт данных**.
2. Скачай ZIP из письма.
3. Открой `index.html` в браузере и загрузи ZIP (или `conversations.json` из него).

Всё считается локально в браузере, файл никуда не отправляется.
Без файла приложение показывает пример на выдуманных данных (помечен плашкой «Пример»).

## Анимации

- Новая карточка раскрывается кругом из точки нажатия.
- Числа считаются от нуля, заголовки появляются по словам, тип пользователя — по буквам.
- На фоне у каждой карточки свой рисунок: пузыри, волны, падающие буквы, звёзды или лучи (по времени суток), квадраты, конфетти.
- Если зажать карточку, она остановится, как в сторис.
- На компьютере карточка наклоняется в 3D за мышкой.
- Сезонные эффекты: 31 октября летают тыквы и летучие мыши, с 1 декабря по 10 января идёт снег.
- При настройке «уменьшить движение» все анимации отключаются.

## Пасхалки (6 штук)

1. Пять быстрых нажатий на оранжевую точку → дождь из конфетти.
2. Десять нажатий на слово «Claude» в заголовке → «Хватит щекотать!».
3. Konami-код ↑↑↓↓←→←→BA (на телефоне три быстрых тапа по надписи «Claude Wrapped» на карточке) → ретро-режим с пиксельным шрифтом.
4. Набрать на клавиатуре «claude» или «клод» → карточка делает сальто.
5. Открыть страницу с полуночи до 5 утра → привет ночным совам.
6. Секретная карточка с достижениями: Новогодняя ночь, Марафонец, Ночной клуб, Пятница 13-е, Железная серия и др. Появляется, только если они заработаны.

Найденные пасхалки отмечаются кружками под плеером; за все шесть — финальный дождь из конфетти.
