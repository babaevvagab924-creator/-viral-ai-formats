# Objects Come Alive

Familiar things with secret lives. Instant relatability ("my fridge would do this") and endless spin-offs by room or object type.

## Ask (max 1 question)
- Which setting/object family? — default: kitchen food.

## Two looks
- **Photoreal-cute** — real-looking objects with subtle eyes and mouths (Pixar-adjacent realism).
- **Claymation** — stop-motion clay texture, very shareable.

## Structure (20–40 s, 6–9 clips)
| Time | Beat |
|---|---|
| 0–2 s | **Human leaves** — door closes, objects' eyes snap open |
| 2–10 s | **Personalities** — 2–3 objects, one trait each (the drama queen, the old wise one) |
| 10–25 s | **Situation** — party, argument, escape plan, competition |
| 25–35 s | **Human returns** — everyone freezes in odd positions |
| 35–40 s | **Tag** — one object moves when the human looks away |

## Hook formulas
- "What your [fridge/desk/bathroom] does when you leave."
- "The [object] knew it was next."
- "Things in your kitchen hate each other. Here's why."

## Workflow
1. **Concept** — cast with one trait each (descriptors), situation, freeze gag. Wait for approval.
2. **Frame prompts** — consistent set, same look line. Wait for approval.
3. **Video prompts** — one action per clip, face animation on the speaker.
4. **Packaging** — subtitle "voices", caption, hashtags.
See `references/models.md`.

## Frame prompt template
```
Vertical 9:16, macro shot of [OBJECT CHARACTER: object + face style + one accessory] [expressive action] on [surface], [other objects reacting], [LOOK LINE: photoreal with subtle cute eyes and mouth / claymation texture], warm kitchen light, shallow depth of field
```

## Video prompt template
```
[Object character] [one action: hops/whispers/rolls/gasps], facial expression changes to [emotion], [secondary object reaction], camera static macro, playful mood, object shape unchanged
```

## Packaging
- Subtitles as speech bubbles or captions ("Banana: I'm not ripe, I'm vintage.").
- Caption: "Which one is you? 👇"
- Hashtags: #ifobjectscouldtalk #funny #claymation #aivideo

## Common mistakes
- Faces too human → uncanny. Keep eyes simple and placement natural to the object.
- Every object talking at once — one speaker per clip.
- Skipping the freeze-when-human-returns gag; it's the most loved beat.

## Example — "The fridge at 3 AM"
**Frame:** `Vertical 9:16, macro shot inside a lit fridge, a nervous egg with tiny dot eyes peeks over the carton edge, a sleepy cheese wedge with heavy eyelids, a stern milk bottle with a monocle-shaped label, photoreal with subtle cute faces, cool fridge light`
**Video:** `The fridge door light flicks on, the egg ducks down into the carton, the milk bottle slowly turns toward camera, camera static macro, comedic tension`
