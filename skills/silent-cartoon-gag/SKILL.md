# Silent Cartoon Gag

No words, pure physical comedy. Works in every country, so one episode can travel globally. Uses original characters only.

## Ask (max 2 questions)
- Your two characters (hero + rival/object)? — default: invent an original duo with opposite shapes (round vs. tall).
- 2D flat or 3D toon? — default: 2D, bold outlines, flat colors.

## Character design rules
- Original designs only — do not imitate existing studio characters.
- Readable silhouette, 3 colors max per character, huge expressive eyes.
- Write a **locked descriptor** + character sheet per character.

## Gag structure (20–45 s, 6–10 clips) — "rule of three"
| Time | Beat |
|---|---|
| 0–3 s | **Want** — hero wants one simple thing (the last cookie) |
| 3–12 s | **Try 1** — fails small |
| 12–22 s | **Try 2** — fails bigger, rival smirks |
| 22–35 s | **Try 3** — elaborate plan, total chaos |
| 35–45 s | **Twist** — rival gets karma, or a third party wins |

## Hook formulas (visual, first frame)
- The desired object glowing with sparkles + hero's giant eyes.
- Mid-action freeze: hero flying through the air toward the goal.

## Workflow
1. **Concept** — duo descriptors, the want, 3 tries, twist. Wait for approval.
2. **Frame prompts** — key poses with squash & stretch, same flat background style. Wait for approval.
3. **Video prompts** — exaggerated cartoon motion, one gag per clip.
4. **Sound cues** — slide whistle, boing, crash, music sting per clip.
See `references/models.md`.

## Frame prompt template
```
Vertical 9:16, 2D cartoon, [HERO DESCRIPTOR] [extreme key pose: stretched/squashed/mid-leap], [RIVAL DESCRIPTOR] [reaction pose], in [simple flat background: kitchen/garden], bold black outlines, flat vibrant colors, comedic exaggeration, clean composition
```

## Video prompt template
```
2D cartoon animation, [character] [one exaggerated action: slips/stretches/zooms], squash and stretch, smear frames, snappy timing, [rival reaction], background static, same character design as start frame
```

## Packaging
- No text needed; optional one-word title card.
- Caption: emoji-only or "Who's team [hero]? 🙋"
- Hashtags: #cartoon #animation #funny #slapstick #aianimation

## Common mistakes
- Too-realistic motion — cartoons need exaggeration and anticipation.
- Characters redesigned each clip — always attach the sheet.
- Fourth or fifth try — three is the comedy rhythm.

## Example — "The last cookie"
**Frame:** `Vertical 9:16, 2D cartoon, Bolt, a small round orange robot with one antenna and big cyan eyes, stretching his arm absurdly long toward a cookie jar on a high shelf, Toasty, a tall grumpy chrome toaster with tiny legs, smirking below, flat pastel kitchen background, bold outlines`
**Video:** `2D cartoon animation, Bolt's arm stretches like rubber toward the jar, it snaps back and smacks his own face, squash and stretch, snappy timing, Toasty pops two slices of toast like laughing, background static`
Sound: stretch creak → boing → toaster "ding".
