# AI Baby Dance

Cute + rhythm + loop. One of the most algorithm-friendly AI formats: rewatchable, sound-driven, zero language barrier.

## Ask (max 1 question)
- Theme (professions, fruits, animals, countries, seasons)? — default: fruit costumes.

## Hard rules
- Babies are **fictional and stylized** (3D animated / toy-like). Never generate from a real child's photo, never photoreal "real baby" deepfakes.
- Wholesome only: costumes, dancing, giggling. Nothing else.
- Label as AI content.

## Structure (10–20 s, 4–8 clips, loopable)
| Time | Beat |
|---|---|
| 0–1 s | **Beat drop** — baby already mid-move |
| 1–12 s | **Costume parade** — 1 baby per beat or per bar |
| 12–18 s | **Group finale** — all together in sync |
| last frame | **Matches first frame** for a seamless loop |

## Hook formulas
- "If fruits were babies 🍓"
- "Baby version of every job"
- "Which baby are you?"

## Workflow
1. **Concept** — theme, 4–6 costumes, trend song tempo (BPM), loop plan. Wait for approval.
2. **Frame prompts** — same art style and age look for all babies. Wait for approval.
3. **Video prompts** — simple bouncy dance moves synced to beat.
4. **Packaging** — trend audio choice, caption, hashtags.
See `references/models.md`.

## Frame prompt template
```
Vertical 9:16, full-body shot of a stylized 3D animated baby character, chubby cheeks, big sparkling eyes, wearing a [costume], [dance pose], on [simple colorful stage/background], soft studio lighting, toy-like Pixar-adjacent 3D render, clearly animated, wholesome
```

## Video prompt template
```
Stylized 3D baby [simple dance move: bounces side to side / claps / spins once / wiggles arms], rhythmic on-beat motion, happy giggle expression, camera static full body, background static, costume unchanged
```

## Packaging
- Use a trending sound from the platform's library (licensed in-app).
- Caption: "Which baby are you? Comment the emoji 👇"
- Hashtags: #babydance #aibaby #cute #trend #aivideo

## Common mistakes
- Photoreal babies → uncanny and risky. Stay clearly stylized.
- Moves too complex for toddler proportions — bounce, clap, spin.
- No loop — match last frame to first.

## Example — "If fruits were babies"
**Frame:** `Vertical 9:16, full-body stylized 3D animated baby with chubby cheeks and big eyes wearing a strawberry costume with a leafy green hat, arms raised mid-dance, pastel pink stage, soft studio light, toy-like 3D render`
**Video:** `Stylized 3D baby bounces side to side on the beat and claps twice, giggling, camera static, strawberry costume unchanged`
