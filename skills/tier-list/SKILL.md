# Tier List / Ranking

Opinions drive comments, and comments drive reach. Every ranking video is a debate starter.

## Ask (max 2 questions)
- Topic and number of items? — default: 6–8 items.
- Tier board (S–F) or countdown (#7 → #1)? — default: tier board.

## Structure (30–60 s, 1 clip per item + board)
| Time | Beat |
|---|---|
| 0–2 s | **Controversial claim** — "Number 1 will make you angry." |
| 2–50 s | **Items** — 4–6 s each: visual + one-line reason + tier placement |
| 50–58 s | **Final board** — all items placed |
| 58–60 s | **Bait** — "Where would YOU put [item]?" |

## Ranking rules
- One clear criterion (deadliest, comfiest, most useful) stated upfront.
- One surprising placement to spark debate — and justify it.
- Facts in reasons must be accurate; opinions labeled as opinions.

## Hook formulas
- "Ranking every [category] from useless to god-tier."
- "I ranked [N] [things]. #1 is not what you think."
- "Which [thing] would you survive? Tier list."

## Workflow
1. **Concept** — criterion, ranked items with one-line reasons, the controversial pick. Wait for approval.
2. **Frame prompts** — one hero image per item, same framing and background style for all. Wait for approval.
3. **Video prompts** — short reveal motion per item (rotate, push-in, dramatic light-up).
4. **Board** — describe the tier board layout for the editor (CapCut/Canva) or build it as a final frame.
5. **Packaging** — captions, title, hashtags.
See `references/models.md`.

## Frame prompt template
```
Vertical 9:16, centered hero shot of [ITEM], [one defining detail], on a [consistent background: dark gradient studio / parchment], dramatic rim lighting, [style line], item fills middle 60% of frame, space at top for tier label
```

## Video prompt template
```
[Item] [reveal motion: slowly rotates / emerges from shadow / camera orbits], dramatic light sweep, camera [push-in], item shape unchanged
```

## Packaging
- Tier letter pops on screen with a sound hit.
- Caption: "Fight me in the comments: where does [controversial item] go?"
- Hashtags: #tierlist #ranking #top10 #[topic] #aivideo

## Common mistakes
- No criterion → ranking feels random.
- All placements obvious → no comments.
- Inconsistent item framing → looks messy; same background for all.

## Example — "Ranking ancient weapons by how scary they'd be to face"
**Frame (Greek fire, S-tier):** `Vertical 9:16, centered hero shot of a bronze siphon nozzle spraying liquid fire across dark water, ancient galley silhouette behind, dark gradient studio background, dramatic orange rim light, cinematic realism`
**Video:** `Flames burst from the nozzle toward camera, embers drift, camera slow push-in, nozzle unchanged`
